# Deployment and operations

[简体中文](../zh-CN/operations.md) · [Developer documentation](README.md)

Check PostgreSQL/migrations, Redis, secrets, reverse-proxy prefixes, deployments, capabilities, scoped access, actual inference, and persisted usage. A healthy process or supplier probe cannot prove all these. Monitor upstream errors/latency/cooldown, quota rejects, guardrails, billing backlog, write failures, and database growth. Correlate request IDs and windows; never log secrets. Backup database/configuration together and test restore/upgrades separately. Production load, network faults, multi-replica coordination, and invoices need environment acceptance.
