# Routing editor contract

[简体中文](../zh-CN/routing-form-design.md) · [Developer documentation](README.md)

Form and JSON preserve explicit zero/false/null/empty arrays. Invalid JSON blocks saving and returning to form. Validate stable deployment IDs, finite weights, required retry fields, cycles, scope, preview side effects, and real selection. Localize help/errors/copy without changing input.

See [testing](testing.md) for isolation, commands, evidence, and external boundaries.
