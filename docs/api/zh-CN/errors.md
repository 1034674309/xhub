# 错误与排查

## 接口概述

按状态码和调用 ID 定位问题。

### 请求与权限错误

400 检查 JSON、模型和参数；401 检查凭据；403 检查角色、模型范围和归属。部分越权返回 404 以隐藏资源存在。

### 限流与上游故障

429 检查 Retry-After 和限流设置。5xx 检查依赖、供应商连接、部署和日志。重试需要退避和次数上限。

### 保留诊断信息

记录时间、模型、状态码和调用 ID。分享前移除密钥、个人信息和敏感内容；流式请求也检查事件错误。

## 接口与认证

使用 XHub API 密钥：Authorization: Bearer <XHUB_API_KEY>。不要把供应商密钥当作网关密钥。

Base URL 使用调试台显示的网关根地址，不额外追加 /v1；实际请求使用上面的完整接口路径。

## 错误与排查

| HTTP | 说明 |
| --- | --- |
| 400 | 请求无效，请检查 JSON、参数和查询。 |
| 401 | XHub 凭据缺失或无效。 |
| 403 | 权限拒绝，请检查模型范围或策略。 |
| 429 | 超过限制，请检查响应详情与 Retry-After。 |
